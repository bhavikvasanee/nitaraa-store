HOW TO ADD YOUR PHOTOS

1. Name each photo exactly as it's written in js/data.js under "image",
   for example: chaniya-D01.jpg
2. Drop the file into this "images" folder.
3. Keep file sizes reasonable (under ~300 KB each) so the site loads
   fast on mobile data — most phone camera photos are fine once you
   use WhatsApp's "Document" send option (not "Photo", which compresses
   too much) to move them to your computer, or resize them using any
   free phone photo editor first.
4. If a photo is missing, the site automatically shows a neat
   placeholder instead of a broken image — nothing breaks, it just
   won't look finished until you add the real photo.

That's it — no renaming tools, no special software needed.
